# 🏥 AI-Powered Voice Recognition System for Healthcare Assistance

## 📘 Description

This project is an **AI-powered healthcare assistance system** designed to help users with basic health-related queries through **text and voice interaction**. The system uses **Natural Language Processing (NLP)** and Machine Learning techniques to analyze user-provided symptoms and provide relevant healthcare information.

The web application is developed using **Flask** and integrates a **Random Forest Classifier** trained on healthcare datasets. Voice assistance is implemented using **Speech-to-Text** and **Text-to-Speech**, allowing users to interact with the system naturally through voice.

The application also includes features such as **user authentication, FAQs, appointment support, and a user dashboard**, providing a simple and interactive healthcare assistance platform.

---

## ⚙️ Technologies Used

* **Python** – Core programming language
* **Flask** – Backend web framework
* **Machine Learning** – Random Forest Classifier
* **NLP** – Symptom and query processing
* **Speech Recognition** – Voice input
* **pyttsx3** – Text-to-Speech functionality
* **HTML & CSS** – Frontend interface
* **JavaScript** – Interactive functionality
* **JSON & CSV** – Healthcare and training datasets
* **bcrypt** – Password security
